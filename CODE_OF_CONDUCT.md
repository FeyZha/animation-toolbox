# Code of conduct / 行为准则

We welcome people of all backgrounds. Be respectful, discuss ideas and observable behavior, and give constructive feedback. Harassment, threats, discrimination, spam, and publishing another person's private information are not acceptable.

These expectations apply to repository issues, pull requests, and other project spaces. Maintainers may remove inappropriate content, close disruptive threads, or restrict participation when needed.

For a concern, ask maintainer [@FeyZha](https://github.com/FeyZha) for help in a repository issue. If the report involves personal or sensitive information, request a private reporting channel without posting those details publicly. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

欢迎不同背景的参与者。请尊重他人、讨论具体问题、提供建设性反馈；不接受骚扰、威胁、歧视、垃圾信息或泄露他人隐私。维护者可按情况移除内容、关闭讨论或限制参与。涉及敏感信息时，先向维护者询问合适的私密渠道，不在公开 Issue 中披露详情。
